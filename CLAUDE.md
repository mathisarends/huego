# huego

Go CLI for Philips Hue bridges, talking directly to the local CLIP v2 REST API
(no cloud account, no Hue app). Ported from the mathisarends/hueify Python
client; project layout modeled after mathisarends/spoti.

## Code style

- No comments explaining what code does — names and structure should make that obvious.
- Only comment the non-obvious: a hidden constraint, why a workaround exists, a subtle invariant.
